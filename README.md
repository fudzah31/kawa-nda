# 🌊 Kawa-Nda | Sistem Kepegawaian Daerah  

> Web-based application for managing local government personnel data,  
> developed during internship as a learning project.  

---

## 📌 About  

Kawa-Nda adalah aplikasi berbasis web yang digunakan untuk membantu  
pengelolaan data kepegawaian daerah, seperti data pegawai, mutasi,  
dan layanan administratif.  

Project ini dibuat dalam proses **magang** dan masih dalam tahap pengembangan,  
dengan fokus pada sistem yang terstruktur dan berbasis data.  

---

## ⚙️ Features  

- 📊 Dashboard sederhana untuk data pegawai  
- 👤 Manajemen data pegawai  
- 🔄 Pencatatan mutasi / perubahan data  
- 🗂️ Pengelolaan kategori & layanan  
- 📱 Tampilan responsif (basic)  

---

## 🛠️ Tech Stack  

- 💻 PHP (Laravel)  
- 🎨 Blade + TailwindCSS  
- ⚡ JavaScript  
- 🗄️ MySQL / MariaDB
