# 🌊 Kawa-Nda | Sistem Kepegawaian Daerah  

> Web-based application for managing local government personnel data,  
> developed during internship as a real-world learning project.  

---

## 📌 About  

Kawa-Nda adalah aplikasi berbasis web untuk membantu pengelolaan  
data kepegawaian daerah secara digital, seperti data pegawai, mutasi,  
dan layanan administratif.  

Project ini dikembangkan selama proses **magang** dan sudah mencakup  
fitur utama yang digunakan dalam alur kerja administrasi.  

---

## ⚙️ Features  

- 🔐 **Authentication System** (Login sesuai data admin)  
- 👤 **Manajemen Data Pegawai**  
- 🔄 **Pencatatan Mutasi / Perubahan Data**  
- 🗂️ **Pengelolaan Kategori & Layanan**  
- 📨 **Pengajuan Permintaan oleh User ke Admin**  
- 📊 **Dashboard Data Pegawai**  
- 📱 **Tampilan Responsif (basic)**  

---

## 🧠 System Flow  

- Admin mengelola data pegawai dan layanan  
- User login sesuai data yang terdaftar  
- User dapat mengajukan permintaan melalui sistem  
- Admin memproses dan memantau data yang masuk  

---

## 🛠️ Tech Stack  

- 💻 PHP (Laravel)  
- 🎨 Blade + TailwindCSS  
- ⚡ JavaScript  
- 🗄️ MySQL / MariaDB  

---

## 🚀 Installation  

git clone https://github.com/username/kawa-nda.git  
cd kawa-nda  
composer install  
npm install  
npm run dev
